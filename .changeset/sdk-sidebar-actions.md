`useWorkflowBuilderActions()` gains `togglePalette`, `setPaletteOpen`, `togglePropertiesPanel`, `setPropertiesPanelOpen` and `setPaletteFilter`. The palette filter matches the translated node label and hides empty groups; node definitions, forms and validation are untouched. The properties panel's collapsed state now lives in the editor store.
