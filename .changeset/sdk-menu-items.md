New `WorkflowMenuItem`, `EditorHeaderMenuItem` and `PropertiesPanelMenuItem` add an item to the workflow menu, the editor header menu and the properties panel menu from anywhere under `<WorkflowBuilder.Root>`; own items follow the built-in ones behind a separator, and an own label may repeat a built-in one. The properties panel gains a menu button whenever it has items.
