`Chip` takes its colours from public variables: `--wb-public-chip-background-color` and `--wb-public-chip-color` for `solid`, `--wb-public-chip-color-outline` and `--wb-public-chip-background-color-outline` for `outline`, with the current look as default. `NodeIcon` takes a `style` prop, so one icon can set `--wb-public-node-icon-color` and `--wb-public-node-icon-container-background-color`.
