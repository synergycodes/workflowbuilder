Exports the current workflow as a PDF file. One click opens an export dialog where users can download it.

The editor header's **Save as PDF** item, in the menu next to the workflow name, appears while something supplies it through `<EditorHeaderSaveAsPdf onSaveAsPdf={…} />` under `WorkflowBuilder.Root`, and runs what was supplied. An app without this plugin can supply its own export the same way. See [What only your app can provide](/guides/build-a-plugin/#what-only-your-app-can-provide-clean-up-save-as-pdf-version-publish).

## Use cases

- Share a workflow diagram with stakeholders who do not have access to the editor.
- Archive a snapshot of a workflow for documentation or compliance purposes.
- Print a large diagram across multiple pages for offline review.
