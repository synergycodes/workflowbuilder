`NodeRunIndicator` is a 20px circle with either a 12px glyph (`icon`) or a 14px spinner (`spinner`).
`tone` sets the circle and, unless `iconTone` is set, the glyph colour.

<NodeRunIndicatorExample client:visible />

## Usage

Put it last in [`NodePanel.Header`](/ui-library/diagram-components/node-panel/). It does not shrink,
so a long title truncates before it.

```tsx
import { Check } from '@phosphor-icons/react';
import { NodeDescription, NodeIcon, NodePanel, NodeRunIndicator } from '@workflowbuilder/ui';

<NodePanel.Header>
  <NodeIcon icon={icon} />
  <NodeDescription label={label} description={description} />
  <NodeRunIndicator tone="success" icon={<Check />} />
</NodePanel.Header>;
```

## Spinner

- `running` - one turn in 0.7s.
- `slow` - one turn in 2.4s, for a step that stopped reporting (No signal).

The track shows the glyph colour at 30%, or 25% in the `warning` tone. With reduced motion the spinner
stops with its arc on top.

## Glyph tone

`iconTone` colours the glyph when it differs from the circle, as in the Rejected status: an
`inverse` glyph on a `neutral` circle.

```tsx
import { X } from '@phosphor-icons/react';

<NodeRunIndicator tone="neutral" iconTone="inverse" icon={<X />} />;
```

The indicator is decorative (`aria-hidden`) by default: the badge text carries the status. HTML
attributes pass through to the circle, so `aria-hidden={false}` with an `aria-label` exposes it.
