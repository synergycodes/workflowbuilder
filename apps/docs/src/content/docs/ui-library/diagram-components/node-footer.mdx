`NodeFooter` is a strip below a divider at the bottom of a node: one line of message, an optional
14px icon before it, and up to two actions after it. `tone` colours the message and the icon; `size`
sets the message in Label S (`s`, the default) or Body S (`m`). A message that does not fit ends with
an ellipsis.

<NodeFooterExample client:visible />

## Usage

Place it in [`NodePanel.Footer`](/ui-library/diagram-components/node-panel/), which sits after
`NodePanel.Content`, not inside it, so the footer stays visible while the content is hidden. Pass actions as
children, for example `Button`s of size `xs`. On the canvas, give each one the `nodrag` class so a
press does not drag the node.

```tsx
import { Button, NodeFooter, NodePanel } from '@workflowbuilder/ui';

<NodePanel.Footer>
  <NodeFooter tone="human" message="Decision needed">
    <Button className="nodrag" variant="ghost-secondary" size="xs" onClick={decide}>
      Decide
    </Button>
  </NodeFooter>
</NodePanel.Footer>;
```

The [run status presets](/ui-library/diagram-components/run-status/) hold the design-system message
of six statuses: `<NodeFooter {...runStatusPresets.failed.footer} />`. In a Workflow Builder node
template, decorate the `OptionalNodeFooter` slot instead (see
[Build a plugin](/guides/build-a-plugin/)).
