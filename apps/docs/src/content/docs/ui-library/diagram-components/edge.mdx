The edge building blocks give diagram edges a consistent look. `EdgeLabel` is a
label primitive designed to sit on an edge, while the `useEdgeStyle` hook
computes the stroke styles for the edge path itself. Both follow the styling
conventions prepared for edges, so a custom edge type matches the built-in ones.

<EdgeExample client:visible />

`EdgeLabel` provides a unified label design for text, icons, or compound content.
Its state (hover, selection, disabled) is managed externally and reflected
through props. It extends a standard `HTMLDivElement` and, by default, uses
`position: absolute` so it can be placed at the `labelX` / `labelY` coordinates
that React Flow provides. Used outside a diagram context it may need extra
wrapper elements or layout adjustments because absolute positioning removes it
from normal document flow.

`useEdgeStyle` returns an object of CSS properties (`stroke`, `strokeWidth`,
`transition`, plus `strokeDasharray` and `animation` when the line is dashed or
running) that you apply directly to the SVG path element representing an edge.
Besides `state` and `isHovered` it takes `runState` (`pending`, `running`,
`completed`, `outOfRun`) to show where the edge stands in an execution run, and
`lineType` (`solid`, `dashed`). The colour follows the first match of:
`disabled`, then `runState`, then `selected` / `temporary`, then hover, then the
default. Once `runState` is set, hover and selection no longer change the
colour. `running` always draws an animated `6 5` dash, even on a `dashed` edge;
otherwise `dashed` draws a static `5 4` dash. Every edge is 1 px wide. The
package also exports the `EdgeState`, `EdgeRunState`, `EdgeLineType` and
`EdgeLabelSize` types and the `EDGE_LABEL_SIZES` constant.

## Usage

`EdgeLabel` is rendered through xyflow's `<EdgeLabelRenderer>` and positioned with
a transform, while `useEdgeStyle` feeds the edge path. The example mirrors the
SDK's default labeled edge.

```tsx
import { EdgeLabel, type EdgeState, useEdgeStyle } from '@workflowbuilder/ui';
import { BaseEdge, EdgeLabelRenderer, type EdgeProps, getSmoothStepPath } from '@xyflow/react';
import { useState } from 'react';

function LabeledEdge({
  id,
  sourceX,
  sourceY,
  targetX,
  targetY,
  sourcePosition,
  targetPosition,
  data,
  selected,
}: EdgeProps) {
  const [hovered, setHovered] = useState(false);
  const state: EdgeState = selected ? 'selected' : 'default';

  const pathStyle = useEdgeStyle({ state, isHovered: hovered });

  const [edgePath, labelX, labelY] = getSmoothStepPath({
    sourceX,
    sourceY,
    sourcePosition,
    targetX,
    targetY,
    targetPosition,
  });

  return (
    <>
      <BaseEdge id={id} path={edgePath} style={pathStyle} />
      {data?.label && (
        <EdgeLabelRenderer>
          <EdgeLabel
            isHovered={hovered}
            state={state}
            style={{ transform: `translate(-50%, -50%) translate(${labelX}px, ${labelY}px)` }}
            onMouseEnter={() => setHovered(true)}
            onMouseLeave={() => setHovered(false)}
          >
            {data.label}
          </EdgeLabel>
        </EdgeLabelRenderer>
      )}
    </>
  );
}
```

To show an execution run, pass the edge's run state. A running edge gets the
running colour and a dash that flows toward the target; under
`prefers-reduced-motion: reduce` the dash stays still.

```tsx
import { type EdgeRunState, useEdgeStyle } from '@workflowbuilder/ui';
import { BaseEdge, type Edge, type EdgeProps, getSmoothStepPath } from '@xyflow/react';

type RunStateEdge = Edge<{ runState?: EdgeRunState }>;

function RunEdge({
  id,
  data,
  sourceX,
  sourceY,
  targetX,
  targetY,
  sourcePosition,
  targetPosition,
}: EdgeProps<RunStateEdge>) {
  const pathStyle = useEdgeStyle({ runState: data?.runState });

  const [edgePath] = getSmoothStepPath({ sourceX, sourceY, sourcePosition, targetX, targetY, targetPosition });

  return <BaseEdge id={id} path={edgePath} style={pathStyle} />;
}

// Rendered for an edge with data: { runState: 'running' }
```

## useEdgeStyle

A hook that maps an edge's `state`, hover flag, `runState` and `lineType` to
the CSS properties for its SVG path.

<PropsTable slug="use-edge-style" />

Returns `{ stroke, strokeWidth, transition }`, plus `strokeDasharray` and
`animation` when they apply, ready to spread onto a path's `style`.
