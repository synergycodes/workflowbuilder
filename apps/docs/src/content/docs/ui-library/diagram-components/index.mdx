The building blocks Workflow Builder uses to render nodes and edges on the canvas.
They are composed inside React Flow node and edge templates rather than used
standalone, so these pages focus on structure and usage.

- [NodePanel](/ui-library/diagram-components/node-panel/) - Node container with `Root`, `Header`, `Content`, `Handles`, and `Overlay` slots.
- [Run status](/ui-library/diagram-components/run-status/) - The design-system run statuses, composed from the parts below.
- [NodeRunRing](/ui-library/diagram-components/node-run-ring/) - Run status line and halo around a node.
- [NodeRunIndicator](/ui-library/diagram-components/node-run-indicator/) - Run status circle at the end of the node header.
- [NodeRunBadge](/ui-library/diagram-components/node-run-badge/) - Run status label above the node's corner.
- [NodeRunProgress](/ui-library/diagram-components/node-run-progress/) - Progress bar under the node header.
- [NodeRunVeil](/ui-library/diagram-components/node-run-veil/) - Dims a node, for example a skipped step.
- [Edge](/ui-library/diagram-components/edge/) - Edge label rendering with hover and selected states.
- [NodeAsPortWrapper](/ui-library/diagram-components/node-as-port-wrapper/) - Turns a whole node into a connection port.
- [NodeDescription](/ui-library/diagram-components/node-description/) - Textual content block inside a node.
- [NodeIcon](/ui-library/diagram-components/node-icon/) - Icon block inside a node.
