`NodeRing` draws a run status over the node: a 1px line in the colour of its `tone` on top of the
node stroke, and an optional halo outside the node. It is one of the run status parts; the
[Run status](/ui-library/diagram-components/run-status/) page shows how they combine.

<NodeRingExample client:visible />

## Usage

Place it in [`NodePanel.Overlay`](/ui-library/diagram-components/node-panel/). The line is an inset
shadow on an absolutely positioned layer, so the node keeps its size.

```tsx
import { NodePanel, NodeRing } from '@workflowbuilder/ui';

<NodePanel.Overlay>
  <NodeRing tone="info" halo="static" />
</NodePanel.Overlay>;
```

## Halo

- `static` - a 3px halo.
- `heartbeat` - pulses between 3px and 6px every 1.4s; a running step that reports progress.
- `waiting` - pulses between 3px and 7px every 1.8s; a step waiting for a person or a service.

Only `info`, `warning` and `human` have a halo colour; with another tone the halo stays transparent.
With reduced motion, `heartbeat` stays a static 3px halo and `waiting` shows no halo.

## Selected node

`NodeRing` carries the `data-node-run-overlay` attribute, so a selected node under it keeps its
selected stroke but drops the focus ring. To show both, set:

```css
:root {
  --wb-public-node-box-shadow-selected-with-run-status: var(--wb-public-node-box-shadow-selected);
}
```

## Custom colour

Override a tone's variable on one instance with a `className`:

```css
.ring-queued {
  --wb-public-node-ring-color-info: #7c3aed;
}
```
