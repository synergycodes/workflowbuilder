`NodeRunProgress` draws a 3px bar 3px above the bottom edge of the node header, inset by the header
padding. Its default `--wb-public-node-run-progress-top` is computed once on `:root` from the header's
min-height: a node that changes its `NodeIcon` size or header needs `--wb-public-node-run-progress-top`
set on that node. A header taller than its min-height, for example with a two-line title, needs
`--wb-public-node-run-progress-top` set to match.
`value` is a percentage, clamped to 0-100; width changes animate over 0.4s, without animation under
reduced motion. Pair it with a `NodeRunRing` in the `heartbeat` halo.

<NodeRunProgressExample client:visible />

## Usage

```tsx
import { NodePanel, NodeRunProgress, NodeRunRing } from '@workflowbuilder/ui';

<NodePanel.Overlay>
  <NodeRunRing tone="info" halo="heartbeat" />
  <NodeRunProgress value={progress} />
</NodePanel.Overlay>;
```

The bar is decorative (`aria-hidden`); announce the run status from the application.
