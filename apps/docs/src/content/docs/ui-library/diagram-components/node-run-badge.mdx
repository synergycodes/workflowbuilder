`NodeRunBadge` is a size `m` [`BadgeLabel`](/ui-library/ui-components/badge-label/) placed 5px above
the node, aligned to its right edge. It grows to the left and never wraps. `tone` picks one of seven
colour pairs, with Light and Dark values; `dimmed` lowers its opacity (Skipped).

<NodeRunBadgeExample client:visible />

## Usage

Place it in [`NodePanel.Overlay`](/ui-library/diagram-components/node-panel/). Write the label in
sentence case; the badge renders it uppercase.

```tsx
import { NodePanel, NodeRunBadge } from '@workflowbuilder/ui';

<NodePanel.Overlay>
  <NodeRunBadge tone="critical" label="Failed" />
</NodePanel.Overlay>;
```

## Custom colours

Each tone reads `--wb-public-node-run-badge-background-color-<tone>`, `--wb-public-node-run-badge-color-<tone>`
and `--wb-public-node-run-badge-icon-color-<tone>`. Override them on `:root` (and
`:root[data-theme='dark']`) or on one instance with a `className`.
