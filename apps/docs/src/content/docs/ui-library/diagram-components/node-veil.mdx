`NodeVeil` lays a translucent layer over the whole node. The Skipped
[run status](/ui-library/diagram-components/run-status/) uses it.

<NodeVeilExample client:visible />

## Usage

Place it in [`NodePanel.Overlay`](/ui-library/diagram-components/node-panel/), after the parts it
should dim.

```tsx
import { NodePanel, NodeRing, NodeVeil } from '@workflowbuilder/ui';

<NodePanel.Overlay>
  <NodeRing tone="neutral" />
  <NodeVeil />
</NodePanel.Overlay>;
```
