A `BadgeLabel` is a short, read-only label: it has no hover, focus or role. It comes in two
sizes (`m` 20px, `s` 16px) and two variants (`default`, `inverse`), with an optional glyph.

<BadgeLabelExample client:visible />

## Usage

```tsx
import { BadgeLabel } from '@workflowbuilder/ui';

function Example() {
  return <BadgeLabel label="Waiting for decision" />;
}
```

To show another status colour, override the colour variables on that instance, for example
with a `className` that sets `--wb-public-badge-label-background-color`.
