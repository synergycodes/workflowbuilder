A `SegmentPicker` is a segmented control that lets users select a single option
from a small, fixed set. Each option is declared with a `SegmentPicker.Item`,
and it can run in controlled (`value`) or uncontrolled (`defaultValue`) mode.

<SegmentPickerExample client:visible />

## Usage

```tsx
import { SegmentPicker } from '@workflowbuilder/ui';
import { useState } from 'react';

function Example() {
  const [view, setView] = useState('list');
  return (
    <SegmentPicker value={view} onChange={(_event, next) => setView(next)}>
      <SegmentPicker.Item value="list">List</SegmentPicker.Item>
      <SegmentPicker.Item value="grid">Grid</SegmentPicker.Item>
      <SegmentPicker.Item value="board">Board</SegmentPicker.Item>
    </SegmentPicker>
  );
}
```

## Secondary variant

`variant="secondary"` renders a compact picker that fits its content: the
segments sit on a padded inset track and the selected one is raised with the
secondary nav-button colours. Use it for small toolbar toggles, such as an
editing mode or a theme switch.

<SegmentPickerSecondaryExample client:visible />

```tsx
import { Moon, SunDim } from '@phosphor-icons/react';
import { SegmentPicker } from '@workflowbuilder/ui';

<SegmentPicker size="extra-small" variant="secondary" value={theme} onChange={(_event, next) => setTheme(next)}>
  <SegmentPicker.Item value="light" aria-label="Light" prefixIcon={<SunDim />} />
  <SegmentPicker.Item value="dark" aria-label="Dark" prefixIcon={<Moon />} />
</SegmentPicker>;
```
